# Todo List

A task management application built with React,
TypeScript, and Tailwind CSS.

## Live Demo

https://M0hamed1hatem7.github.io/todo-list/

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

Clone the repository:

git clone https://github.com/M0hamed1hatem7/todo-list.git

Install dependencies:

npm install

Run development server:

npm run dev

Build for production:

npm run build
